# Wirework

[![License: Apache-2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

An original-world 2D pixel-art **top-down wall-defense ODM action** game. You
pilot an omni-directional mobility (ODM) grapple rig across a besieged arena,
defending a **concentric double ring** fortification — an **outer ring** and an
**inner ring** — that shelters the citizens clustered at its center. Waves of
giant humanoids ("Ravagers") siege inward from every angle, breaching the outer
ring, then the inner ring, to reach and devour the citizens. Move in eight
directions, dash and grapple across the plane, and strike a giant's exposed
**nape** for a critical kill. Keep your gas topped up and hold the line across
every wave.

> **Original work / IP boundary.** Wirework is an **original** game *inspired by*
> the wall-defense / grapple-action genre. All names, lore, enemy archetypes,
> art, and audio are original to this project. It does **not** use "Attack on
> Titan" (or any other third-party) names, characters, canonical creature names,
> factions, story, or sprites. See [`assets/CREDITS.md`](assets/CREDITS.md) for
> full asset provenance.

**Play the live build:** <https://savagemanage.github.io/wirework/>

## Tech stack

- [Phaser 3](https://phaser.io/) — 2D game framework (arcade physics, WebAudio)
- [TypeScript](https://www.typescriptlang.org/) — strict, typed source
- [Vite](https://vitejs.dev/) — dev server + production bundling
- Original assets generated by Python scripts in [`tools/`](tools/) (Pillow for
  pixel art, stdlib synthesis for SFX/music)

Logical resolution is a crisp **960×540** pixel canvas scaled to fit the window
with nearest-neighbour rendering for the world and higher-DPI rendering for UI
text. The view is **top-down** with no gravity — all movement is planar.

## Getting started

Requires **Node 20**.

```bash
npm install       # install dependencies
npm run dev       # start the Vite dev server (hot reload)
npm run build     # type-check + production build into dist/
npm run preview   # preview the production build locally
npm run typecheck # type-check only (tsc --noEmit)
```

Open the dev server URL that Vite prints (default <http://localhost:5173>).

## Controls

| Input                         | Action                                                |
| ----------------------------- | ----------------------------------------------------- |
| `W` `A` `S` `D` or arrow keys | Move in eight directions (planar, no jump)            |
| `Shift`                       | **Omnidirectional dash** toward the aim direction     |
| **Hold Left-click**           | Fire and hold the grapple wire; **release to fling**  |
| **Right-click**               | Aimed blade slash (hit the **nape** for a critical)   |
| `Q` / `E` while grappled      | Reel in / reel out the wire                           |
| `P`                           | Pause (resume / settings / quit-to-title)             |
| `Esc`                         | Abandon the current run                               |

Menus: `Space` deploys and `S` opens Settings from the Title; on the game-over
screen `R` retries and `Space` returns to the Title. An on-screen **weak-point
cue** lights up when your aim is on a giant's nape and goes "hot" when a slash
there will connect.

## Gameplay

- **Objective:** defend the concentric double ring and the citizens at its
  center across all waves. Clearing every wave is a **victory**; the run ends if
  the **inner ring** falls, every citizen is devoured, **or the hero's own
  health runs out**.
- **The arena:** giants spawn around the **outer ring** at every angle and press
  inward. They chip the nearest outer-ring segment until it breaches, then move
  on to the **inner ring**, then to the citizens at the center. Each ring is
  split into breachable arc segments with their own integrity.
- **Stay alive:** giants that reach you swing at your body, and Throwers hurl
  debris across the plane. A hit costs health, knocks you back, and grants brief
  invulnerability (i-frames). Watch the **HP** gauge — dying loses the run.
- **Six original giant roles:** Wanderer, Sprinter, Breaker, Aberrant, Armored,
  and Thrower — each with a distinct silhouette, behaviour, and the tell-tale
  nape weak-point.
- **Gas / stamina:** firing the grapple, reeling, and dashing all spend gas,
  which regenerates fastest when you are not flinging on a wire. The HUD shows
  HP, gas, outer- and inner-ring integrity, wave, score, and citizens remaining.
- **Settings:** master / SFX / music volume sliders and a difficulty selector.
  Volumes are applied live and **persisted to `localStorage`**. Difficulty
  (**relaxed / standard / brutal**) is read at the start of a run and scales
  wave **pacing** and, at the top setting, adds a few extra baseline giants per
  wave — it never buffs individual giant stats. All settings survive reloads.

## Project structure

```
src/
  main.ts          Phaser.Game bootstrap + scene list
  config/          Centralized, config-driven tuning (Game/Player/Enemy/Wave)
  scenes/          Boot, Preload, Title, Settings, Game, Pause, GameOver

  systems/         ODM grapple physics, gas, combat, waves, AudioManager

  types/           Shared cross-cutting types
public/assets/     Original sprites, backgrounds, UI, FX, and audio

```

## Deployment (GitHub Pages)

The production build sets the Vite `base` to `/wirework/` so asset URLs resolve
under the project-pages path.

### Automatic (GitHub Actions — recommended)

Pushes to `main` trigger [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml),
which runs `npm ci && npm run build`, uploads `dist/` as a Pages artifact, and
publishes it with `actions/deploy-pages`. Enable **Settings → Pages → Build and
deployment → Source: GitHub Actions** on the repository once, and every push to
`main` redeploys to <https://savagemanage.github.io/wirework/>.

### Manual (`npm run build` + `gh-pages` fallback)

If you prefer to publish by hand (or Actions is unavailable):

```bash
npm run build                     # produces dist/
npx gh-pages -d dist              # push dist/ to the gh-pages branch
```

Then set **Settings → Pages → Source: Deploy from a branch → `gh-pages` / root**.
The site serves at the same <https://savagemanage.github.io/wirework/> URL.
