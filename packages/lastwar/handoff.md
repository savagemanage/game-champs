# Handoff — LAST SQUAD (라스트 스쿼드)

An original, Korean‑first (한국어, EN toggle) web game inspired by the "Last War:
Survival" genre — a base‑building / hero‑collection / auto‑battler hub plus the
viral lane **gate‑runner** mini‑game ("팔콘 구조대"). Built as a fully static,
client‑only site and deployed to GitHub Pages.

- **Live:** https://savagemanage.github.io/game-lastwar/
- **Repo:** https://github.com/savagemanage/game-lastwar
- **Default branch:** `main` (all work is merged here; deploys from `main`)

> **IP boundary.** Original work inspired by the genre. No trademarked "Last War"
> name, no real hero names/quotes/art. All names, lore, art, and audio are
> original. "Last War" appears only in the not‑affiliated disclaimer in
> `README.md` / `assets/CREDITS.md`. The repo slug `game-lastwar` is only a
> deployment identifier.

## How to run

Requires **Node 22+**.

```bash
npm install       # install dependencies
npm run dev       # Vite dev server (http://localhost:5173)
npm run build     # tsc --noEmit (strict) + vite build -> dist/
npm run preview   # preview the production build
npm run typecheck # type-check only
npm run test      # vitest (233 tests across 20 files, all green)
```

Both `npm run build` and `npm run test` are green as of this handoff.

## Tech stack

- **Phaser 3** (canvas game framework), **TypeScript** (strict), **Vite** (build),
  **Vitest** (unit tests for the pure‑logic systems).
- Original assets generated by **Python** scripts in `tools/`
  (`gen_sprites.py` = Pillow; `gen_audio.py` = stdlib; `build_font.py` = font
  subsetting), committed under `public/assets/`.
- Korean‑first i18n in `src/i18n/` (KO/EN string table + tiny runtime).

with real Vitest coverage; scenes render/drive those systems.

## Game loop (what's playable)

Title → **Home hub ("베이스 캠프")** with bottom nav:
- **기지 (Base):** building tree + resource economy with offline accrual.
- **영웅 (Heroes):** recruit (gacha + pity), tier/level/skill progression.
- **편성 (Formation):** 2 front / 3 back squad; tank > missile > aircraft
  type triangle; +20% same‑type buff.
- **전역 (Campaign):** stages (resistance‑gated) + endless horde/zombie waves →
  animated **Battle** (deterministic auto‑combat replayed from an event timeline).
- **임무 (Missions):** daily arms‑race + weekly duel + an offline **League**
  (single‑player AI simulation).
- **시즌 (Season):** battle‑pass track + resistance opener.
- **팔콘 구조대 (Falcon Rescue):** the lane gate‑runner mini‑game; results feed
  shards/resources/season‑XP back into the base economy.

Persistence: versioned `localStorage` save via `SaveManager` (fail‑soft, with
migrations). A skippable/replayable **first‑run tutorial** auto‑shows for new
players; "플레이 방법" replays it from the Title.

## Platform reality (important)

GitHub Pages is a **static, client‑only** host — there is **no backend and no
real multiplayer**. Everything in the spec that would need servers (alliances
with real players, real‑time battlegrounds, cross‑server PvP/leagues, chat) is
implemented as **single‑player AI simulations** persisted to `localStorage`. Do
not assume any server exists.

## Deployment

- `.github/workflows/deploy.yml` builds on every push to `main`
  (`npm ci && npm run build`) and publishes `dist/` to GitHub Pages.
- GitHub Pages **Source = GitHub Actions** must stay enabled in repo Settings
  (one‑time; already enabled).
- `vite.config.ts` sets production `base` to **`/game-lastwar/`** — keep this
  exactly; assets resolve base‑aware via `assetPath()` /
  `import.meta.env.BASE_URL`. Never hardcode absolute asset paths.
- **CI safety:** never push changes to `.github/workflows/*` directly to `main`;
  route CI‑config changes through a reviewed PR.

## Rendering notes (hard‑won; don't regress)

The game had a series of text/layout bugs; the current, correct configuration:
- **No** `pixelArt: true`, **no** `roundPixels: true`, **no**
  `image-rendering: pixelated` on the canvas — those nearest‑neighbour‑scaled
  the whole canvas and mangled small Korean text. Text now scales smoothly.
- Pixel‑art **sprites** stay crisp via **per‑texture NEAREST** filtering applied
  in `PreloadScene` (not by pixelating the whole canvas).
- Canvas is centered with `Scale.FIT` + `Scale.NO_CENTER` + a flex `#game`
  parent + `#game canvas { margin:0; display:block }` (Phaser `autoCenter` and
  the flex parent double‑centered → do not re‑enable `autoCenter`).
- Backing‑buffer resolution scales with devicePixelRatio via `scale.zoom`
  (see `src/systems/RenderScale.ts`), keeping 540×960 as the logical space.
- Hangul renders with a **self‑hosted vector webfont, Noto Sans KR (OFL‑1.1)**,
  subset by `tools/build_font.py`; boot waits on `document.fonts` before Phaser
  draws text (see `src/main.ts`). The earlier pixel font (Galmuri) was removed
  because it smeared at small non‑integer sizes.
- Shared text style + a minimum UI font size live in `src/ui/UiText.ts`
  (`UI_MIN_FONT_SIZE`, with an `allowSmall` opt‑out for dense fixed‑width
  labels).

If you regenerate the font, re‑run `tools/build_font.py` and re‑verify glyph
coverage against `src/i18n/strings.ts` (a known caveat: keep any UI symbol
glyphs — arrows `→ ← ↓`, `× ÷` — inside the subset).

## Known follow‑ups / deferred scope (non‑blocking)

- The Phaser **scene layer has no unit tests** (no scene harness); scene logic is
  verified by reading + the pure‑system tests + live browser screenshots.
- **Alliance/League/PvP are AI simulations**, not networked (platform reality).
- The bundled font subset is regenerated by `build_font.py`; a stale subset can
  drop uncommon glyphs — keep UI to glyphs known to be in the subset, or
  regenerate and re‑verify.
- At **dpr = 1** on a small desktop window the canvas may still FIT‑downscale a
  540‑wide buffer slightly; legibility is carried by the raised font sizes.
  Higher‑DPI displays get a larger backing buffer automatically.
- No CI pushes directly to `main` for workflow files — use a PR.
