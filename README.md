# Wirework

An original-world 2D pixel-art **wall-defense ODM action** game. You pilot an
omni-directional mobility (ODM) grapple rig, swinging above a besieged city to
cut down waves of giant humanoids ("Ravagers") before they breach the wall and
devour the citizens sheltered behind it. Strike a giant's exposed **nape** for a
critical kill, keep your gas topped up, and hold the line across every wave.

> **Original work / IP boundary.** Wirework is an **original** game *inspired by*
> the wall-defense / grapple-action genre. All names, lore, enemy archetypes,
> art, and audio are original to this project. It does **not** use "Attack on
> Titan" (or any other third-party) names, characters, canonical creature names,
> factions, story, or sprites. See [`assets/CREDITS.md`](assets/CREDITS.md) for
> full asset provenance.

**Play the live build:** <https://savagemanage.github.io/wirework/>

## Tech stack

- [Phaser 3](https://phaser.io/) — 2D game framework (arcade physics, WebAudio)
- [TypeScript](https://www.typescriptlang.org/) — strict, typed source
- [Vite](https://vitejs.dev/) — dev server + production bundling
- Original assets generated by Python scripts in [`tools/`](tools/) (Pillow for
  pixel art, stdlib synthesis for SFX/music)

Logical resolution is a crisp **480×270** pixel canvas scaled to fit the window
with nearest-neighbour rendering.

## Getting started

Requires **Node 20**.

```bash
npm install       # install dependencies
npm run dev       # start the Vite dev server (hot reload)
npm run build     # type-check + production build into dist/
npm run preview   # preview the production build locally
npm run typecheck # type-check only (tsc --noEmit)
```

Open the dev server URL that Vite prints (default <http://localhost:5173>).

## Controls

| Input                         | Action                                              |
| ----------------------------- | --------------------------------------------------- |
| `A` / `D` or `←` / `→`        | Run left / right                                    |
| `W` / `Space`                 | Jump                                                |
| **Hold Left-click**           | Fire and hold the grapple wire; **release to fling**|
| **Right-click**               | Aimed blade slash (hit the **nape** for a critical) |
| `W` / `S` while swinging      | Reel in / reel out the wire                         |
| `Shift`                       | Dash burst toward the aim / movement direction      |
| `P`                           | Pause (resume / settings / quit-to-title)           |
| `Esc`                         | Abandon the current run                             |

Menus: `Space` deploys and `S` opens Settings from the Title; on the game-over
screen `R` retries and `Space` returns to the Title. An on-screen **weak-point
cue** lights up when your aim is on a giant's nape and goes "hot" when a slash
there will connect.

## Gameplay

- **Objective:** defend the wall and the citizens behind it across all waves.
  Clearing every wave is a **victory**; losing the wall or all citizens ends the
  run.
- **Six original giant roles:** Wanderer, Sprinter, Breaker, Aberrant, Armored,
  and Thrower — each with a distinct silhouette, behaviour, and the tell-tale
  nape weak-point.
- **Gas / stamina:** firing the grapple, reeling, and dashing all spend gas,
  which regenerates fastest when you are grounded. The HUD shows gas, wall
  integrity, wave, score, and citizens remaining.
- **Settings:** master / SFX / music volume sliders and a difficulty selector.
  Volumes are applied live and **persisted to `localStorage`**, so they survive
  reloads.

## Project structure


## Deployment (GitHub Pages)

The production build sets the Vite `base` to `/wirework/` so asset URLs resolve
under the project-pages path.

### Automatic (GitHub Actions — recommended)

Pushes to `main` trigger [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml),
which runs `npm ci && npm run build`, uploads `dist/` as a Pages artifact, and
publishes it with `actions/deploy-pages`. Enable **Settings → Pages → Build and
deployment → Source: GitHub Actions** on the repository once, and every push to
`main` redeploys to <https://savagemanage.github.io/wirework/>.

### Manual (`npm run build` + `gh-pages` fallback)

If you prefer to publish by hand (or Actions is unavailable):

```bash
npm run build                     # produces dist/
npx gh-pages -d dist              # push dist/ to the gh-pages branch
```

Then set **Settings → Pages → Source: Deploy from a branch → `gh-pages` / root**.
The site serves at the same <https://savagemanage.github.io/wirework/> URL.
