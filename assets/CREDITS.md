## Audio (FEAT-002)

### Downloaded (license-verified)

- **File:** `assets/audio/ui_click.ogg`
  **Source URL:** https://kenney.nl/assets/interface-sounds (pack: "Interface Sounds" 1.0, file `Audio/click_001.ogg`)
  **Author:** Kenney (www.kenney.nl)
  **License:** CC0 1.0 (public domain) — https://creativecommons.org/publicdomain/zero/1.0/
  **Notes:** Real OGG Vorbis (mono, 44100 Hz), verified with `file` (Ogg/Vorbis, ~4.8 KB, not an HTML error page). Used for the UI click sfx (`SfxBank.UI_CLICK`). Its sibling `.import` is NOT committed because this repo's `.gitignore` excludes `*.import` (same policy as the generated `ui.*.translation` files); a one-time editor open regenerates `assets/audio/ui_click.ogg.import` + `.godot/imported/…oggvorbisstr`. Until then the OGG will not load in a headless run — the ten procedural WAV `.tres` clips below need no import and always work, so the game is never silent by construction.
